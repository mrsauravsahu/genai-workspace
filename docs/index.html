Hand off a task and Claude sorts it into three states while you keep coding.

  • needs input — sessions with a question or a decision for you
  • working — still running, even if you close the terminal
  • completed — finished, waiting for review

the idea

.friday — one source of truth

Rules, MCP config, skills, and commands live once in .friday/. Every harness reads from its own path, so .friday/init symlinks the canonical files into place.

  • before
  • .claude/ — its own rules, skills, mcp
  • .cursor/ — duplicated rules
  • .opencode/ — duplicated again
  • after
  • .friday/
  • CLAUDE.md → .friday/rules.md
  • AGENTS.md → .friday/rules.md
  • .mcp.json → .friday/mcp.json
